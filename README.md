## 🧐  목표 계획서.

### 요구 사항.

- 제공된 라이브러리 & 스타일 라이브러리를 제외한 라이브러리 사용 금지
- 프로그램 종료 시 process.exit()를 호출 X.
- 파일, 페키지 이름 변경 및 이동 금지.
- 프로그램 실행의 시작점은 `App.js`의 `run()`.
- 입력.
  - `:` || `,` 을 구분자로 이용.
  - 커스텀 구분자는 `//` 와 `\n` 사이에 존재.
- 출럭.
  - 구분자를 기준으로 숫자를 분리하여 합한 숫자를 출력.
  - 예외 처리.
    - 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시킨 후 애플리케이션은 종료되어야 한다.

### **학습 키워드.**

- Airbnb 스타일 가이드.
- Angular JS 커밋 컨벤션.
- `Console` API.
